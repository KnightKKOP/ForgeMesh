# ADR-011: 插件与工作流版本固定

- 状态: Accepted
- 日期: 2026-10-09
- 决策者: ForgeMesh 架构组
- 相关: architecture.md 第 2、8、12 章；development-plan.md 1.2、WP-2.1、WP-4.6

## 背景

插件与工作流定义会持续升级。如果升级会静默改变正在运行的任务/实例所使用的定义或插件行为，就可能造成不可预期的执行结果、难以复现的问题与审计困难；对于长时间运行的工作流尤其危险。

## 决策

**插件与工作流版本固定**：

- 每个运行实例**记录其使用的定义版本与插件版本**；执行历史可追溯到实际使用的版本。
- **升级不能破坏正在运行的任务**：升级期间**新旧版本并存**，运行中的实例继续使用其初始版本，新实例才使用新版本。
- **不静默改变**既有工作流实例的执行定义；若需变更运行中实例，须显式迁移并记录。
- 版本信息作为稳定标识的一部分，纳入审计与可观测数据（对齐不变量四）。

## 后果

**正面**

- 升级安全、行为可复现，工作流历史可精确追溯。
- 新旧版本并行让发布与运行解耦，降低升级风险。

**代价与约束**

- 需同时维护多个插件/定义版本，存储与兼容测试成本上升。
- 需要明确的版本固定与迁移机制，避免"漂移"。
- 与 ADR-012 协同：版本前缀与兼容性测试须覆盖插件协议与工作流定义。
